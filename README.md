# 🌸 Гортензия — Мой сад (Android 1.7)

Русскоязычное Android-приложение для коллекции гортензий. Советы по уходу за метельчатой гортензией подготовлены на основе предоставленного пособия; для других видов эти советы могут быть неприменимы. Без оплаты и регистрации работает **личный дневник** и встроенные изображения-превью первых 12 карточек. **Общий альбом** фотографий других пользователей доступен после подключения владельцем приложения *одного общего* облачного проекта Supabase.

## Возможности

- **Расширенный каталог v1.7:** 101 запись о культурных формах и сортах из RHS (включая 12 исходных) для семи ботанических видов, плюс отдельный поисковый индекс 101 научного названия видов и межвидовых гибридов на основе Kew POWO. Индекс **не объявлен официальным списком принятых видов**: Kew отдельно приводит число принятых названий, а состав таксонов периодически меняется. Список культурных сортов открыт для дополнений и не претендует на все существующие культивары. Доступны поиск, выбор вида, карточки сортов и постраничный просмотр. [Источники каталога](CATALOG_SOURCES.md).
- **Фотографии:** для первых 12 карточек встроены офлайн-фото-превью, сделанные из фото гортензии из пользовательского пособия. Это **иллюстрации гортензии, не подтверждённые фотографии конкретных сортов**. Для новых записей без документально подтверждённого фото показывается пустая карточка вместо подмены. На всех карточках разрешено добавить собственное локальное фото. Для восьми исходных сортов сохранены ссылки на страницы Commons с подписями и лицензиями, но картинки не загружаются автоматически. [Происхождение иллюстраций](PHOTO_CREDITS.md).

- **Собственные сорта:** в «Справочник → Сорта» можно добавлять, редактировать и удалять записи с названием, ботаническим видом, высотой, окраской, временем цветения и заметками (до 100). Свои сорта доступны при создании карточки куста; прямо в форме куста можно создать недостающий сорт без потери введённых полей. При переименовании сорта названия в связанных карточках обновятся, при удалении сорта сохранится текст сорта в карточках. Встроенный справочник не изменяется. Личные сорта хранятся офлайн и входят в JSON-резервную копию.


- Добавление кустов, сортов и заметок, календарь ухода, журнал поливов/обрезки/подкормок, рекомендации и справочник.
- **Фотодневник v1.3:** дата съёмки, этап роста (бутонизация, цветение и др.), собственные заметки для каждого фото, хронологический показ снимков и сравнение пары «до / после». Подписи и даты не передаются в общий альбом автоматически; для публикации требуется отдельное согласие и ввод публичной подписи.
- **Сравнения v1.4:** сохраняйте выбранную пару снимков с названием, открывайте сохранённое сравнение из карточки куста и удаляйте его отдельно от фотографий. Сохранённые ссылки на фото включаются в JSON-копию; сами файлы фото в неё не входят. При удалении фото связанные сравнения удаляются.
- **Календарь цветения v1.4:** отмечайте начало и окончание цветения каждого года и собственные заметки, смотрите датированные снимки с этапом «Цветение» по годам. Фото-наблюдения не считаются автоматически датами начала/окончания.
- **Поиск по саду v1.3:** название куста, сорт или место; фильтры «Проверить почву» и «С фотографиями».
- **Личная фотоистория:** выбрать фотографию каждого куста через стандартный системный выбор изображений Android, до 12 фото на куст. JPEG-копии уменьшены до 1600 пикселей и сохраняются внутри приложения **без копирования EXIF/геометок**. Android не запрашивает общий доступ к галерее или геолокации.
- **Общий альбом (опционально):** владелец снимка явно выбирает «В альбом», псевдоним и подпись, подтверждает согласие. Публикация поступает в очередь и видна другим пользователям только после проверки модератором. Просмотр сортов, чужих результатов, жалобы и удаление собственной публикации. Чата, адресов и публичных профилей нет.
- Общий альбом работает через анонимный аккаунт Supabase, таблицы с row-level security и **private** Storage, в котором изображения доступны по временным ссылкам только владельцу и после одобрения другим пользователям. Записи личного сада, местоположение растения, собственный каталог сортов и история ухода в общий альбом не передаются. Название сорта в публикации передаётся только после явного согласия владельца снимка. Добавление сорта не создаёт общедоступный сорт в облаке.
- JSON-резервная копия содержит записи, подписи/даты/этапы фотоистории и собственные сорта (включая импорт резервных копий v1.0/v1.1/v1.2), но **не байты фотографий**: при переносе на другой телефон фото надо перенести отдельно; имеющиеся локальные ID без файлов превью не покажут. Для переноса снимков сохраните исходные фото в галерее. Опубликованные снимки **не являются резервной копией личного сада**.

> Для общественного сервиса потребуется работающий Supabase-проект, модератор, правила публикации/удаления и проверка доступа с разных устройств. Без конфигурации облака личные фото и старые функции полностью доступны, а общий альбом показывает объяснение, почему он ещё не подключён.

## 🛠️ Получить APK через GitHub

1. Загрузите **содержимое** проекта в новый GitHub-репозиторий (включая скрытую папку `.github`).
2. Откройте **Actions → Android APK → Run workflow**. Готовый APK доступен в **Artifacts** после успешной сборки. Потребуется доступ к Google Android SDK/Gradle в GitHub Actions. Здесь APK не приложен: в архиве исходный проект.
3. **Для общего альбома** сначала выполните [`supabase/SETUP.md`](supabase/SETUP.md), а в **GitHub Settings → Secrets and variables → Actions** добавьте общие для всех установок `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Запускайте сборку после добавления секретов. Не добавляйте в APK `service_role` и не публикуйте файл `supabase.properties`.
4. Если хотите пока только личные фото, ничего не настраивайте: приложение собирается с пустой облачной конфигурацией.

## 🧪 Локальная разработка

Минимальная версия: Android 6.0 / API 23. `compileSdk=35`, `targetSdk=34`, JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Kotlin 2.0.21. В репозитории нет бинарного Gradle Wrapper. Откройте проект в Android Studio или запустите `gradle :app:assembleDebug` при установленном Android SDK и Gradle. Для личной облачной конфигурации используйте `supabase.properties` по образцу `supabase.properties.example`.

Проверить JS: `node tests/test_core.js`, затем `node --check app/src/main/assets/app.js` и `node --check app/src/main/assets/catalog_expanded.js`. Файл `app/src/main/assets/index.html` можно открыть в браузере только для предпросмотра интерфейса; системный Android Photo Picker, локальные изображения и облачный Bridge там не работают.

**Внимание:** автоматические тесты JavaScript и статическая проверка не подтверждают, что Android APK уже успешно собран или что облачный сервис был реально протестирован: для этого нужны ваша конфигурация Supabase и сборка на Android/GitHub.

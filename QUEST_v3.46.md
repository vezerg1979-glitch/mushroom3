# Тихая охота — фото-квест v3.46

Выбор маршрута на развилке, переходы между локациями, осмотр мест и корзинка. Работает без сети. Изображения — фотоподобные ИИ-концепты, НЕ документальные фотографии настоящего леса. Для замены на настоящие лицензированные фотографии достаточно заменить файлы android/assets/forest_quest/*.jpg. Маршруты вымышленные, не связаны с реальной GPS-картой.

# v3.40 — независимый резервный прогноз

- При сбое Open-Meteo данные MET Norway преобразуются в формат модели Day.
- MET Norway предоставляет прогноз, но не 31-дневную историю осадков и не почвенные измерения.
- Если кэш истории существует, используется он; иначе запускается модель с нейтральной инициализацией. Внутренний период инициализации не является наблюдаемой погодой: результат помечается как ограниченный.
- Для ET0 в резервном режиме используется грубая оценка по температуре, а для почвы — встроенный водный баланс и сглаживание температуры.
- В ответе MET Norway не суммируются перекрывающиеся 1- и 6-часовые осадки.
- Кэш Open-Meteo остаётся резервом, если оба сервиса недоступны.
- Погодные данные MET Norway представлены по датам UTC; в пограничные часы возможен сдвиг относительно местных суток.
- Тесты: 1222 passed, 11 skipped. Реальный Android APK не собирался, сетевые обращения с телефона не проверялись.

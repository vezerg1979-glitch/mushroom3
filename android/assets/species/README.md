# Свои фотографии видов

Файл `<slug>.jpg` (или `.jpeg`, `.png`) в этом каталоге заменяет рисунок из
`atlas.py` в окне «Что нашли?» и в карточке вида. Имена берутся из таблицы
`SLUG`:

belyi, podberezovik, podosinovik, lisichka, maslenok, openok, gruzd,
syroezhka, veshenka, smorchok, strochok

Латиницей намеренно: кириллица в путях внутри APK на разных прошивках ведёт
себя по-разному.

Что стоит держать в голове, подбирая кадр:

* Гриб целиком, вместе с основанием ножки. Именно там у сыроежки видно, есть
  ли мешочек-вольва, а это разница между ужином и реанимацией.
* Ровный дневной свет, спокойный фон. Снимок со вспышкой в сумерках врёт по
  цвету сильнее, чем схематичный рисунок.
* Квадрат: виджет вписывает картинку по меньшей стороне и обрезает лишнее.
* Свой снимок или снимок с явно разрешающей лицензией. Чужая фотография из
  поиска в APK — нарушение, из-за которого сборку снимут с публикации.

Каталог намеренно пустой: в репозитории лежат только рисунки, права на
которые есть у проекта.

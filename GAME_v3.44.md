# Тихая охота v3.44
- Три лесные цветовые атмосферы (утренний хвойный лес, золотистый просвет, туманный ельник).
- Многоплановые деревья, подлесок, листва, травы и папоротники с воспроизводимым размещением.
- Очень мягкое изменение яркости солнечного просвета во времени.
- Анимация отключается при закрытии игры, чтобы не расходовать батарею.
- Игровые правила, карта и погодная модель не изменены.
- Звуки природы пока не добавлены: для них нужны лицензированные локальные аудиофайлы.

# Дизайн v3.41

Изменения Android: 1) тёплый светлый фон; 2) лесная тёмная палитра; 3) тёмные карточки; 4) согласованные вторичные поверхности; 5) крупнее заголовок прогноза; 6) больше внутренние отступы карточки; 7) увеличена кнопка радара; 8) больше расстояние между днями календаря; 9) просторнее шкала индекса и прокручиваемая страница; 10) понятнее сообщение о загрузке нескольких погодных источников.

Карта, GPS, прогнозная модель и сетевые алгоритмы не менялись. Проверка на реальном Android необходима.
